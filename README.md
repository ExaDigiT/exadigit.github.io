# exadigit.github.io

Source for the [ExaDigiT](https://exadigit.github.io) project landing page, a static site built with plain HTML/CSS and served via GitHub Pages.

ExaDigiT is an open, modular digital twin framework for modeling, simulating, and visualizing liquid-cooled supercomputers. Project source code lives across the repos in this [GitHub org](https://github.com/orgs/ExaDigiT/repositories) (mirrored from our [ORNL GitLab](https://code.ornl.gov/exadigit)).

## Editing the site

- `index.html` / `workgroups/index.html` - page content
- `styles.css` - styling
- `images/` - site assets

Changes pushed to `main` are published automatically by GitHub Pages.
